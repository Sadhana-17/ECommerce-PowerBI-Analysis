# E-Commerce Sales & Customer Analysis Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard developed to analyze
e-commerce sales, profitability, products, customers, regions, and
payment behavior.

The project contains 400 sales transactions and provides insights
through three interactive dashboard pages.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Modeling
- Data Visualization

## 📁 Dataset

The dataset contains information about:

- Order ID
- Order Date
- Customer
- Product
- Category
- Region
- State
- City
- Customer Segment
- Quantity
- Sales
- Profit
- Payment Mode
- Sales Channel

## 📌 Dashboard Pages

### 1. Executive Dashboard

Analyzes:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Monthly Sales
- Sales by Category
- Sales by Region
- Sales by Sales Channel

### 2. Product Analysis

Analyzes:

- Top 10 Products by Sales
- Top 10 Products by Profit
- Profit by Category
- Quantity Sold by Category
- Sales vs Profit by Product

### 3. Customer & Regional Analysis

Analyzes:

- Total Customers
- Average Order Value
- Top 10 Customers
- Sales by City
- Sales by State
- Sales by Customer Segment
- Sales by Payment Mode

## 🔧 Data Preparation

Power Query was used to:

- Check data types
- Remove duplicate transactions
- Validate the datasets
- Prepare the data for analysis

## 🧮 DAX Measures

The project includes measures such as:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin
- Average Order Value
- Total Customers

## 💡 Key Insights

The dashboard helps identify:

- Best-performing product categories
- Top-selling products
- Most profitable products
- Regional sales performance
- Customer segments
- Payment preferences
- Monthly sales trends
